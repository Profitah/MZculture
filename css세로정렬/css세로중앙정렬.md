## css 세로 중앙 정렬 업데이트 예정
2024년, css에 혁신적인 변화가 일어날 예정이다.<br>
이 업데이트가 결정되기 전까지만 해도 css 세로 중앙 정렬은 고오급 기술이였는데, 2024년 css 패치로 인해 세로 중앙 정렬을 하기 무척 편리해졌다.<br>

**css 세로 중앙 정렬은 `align-content : content`를 사용하면 쉽게 할 수 있다.**

## 사용예시
``` html
<!DOCTYPE html>
  <head>
    <meta charset="utf-8">
  </head>
  <body>
    <div style="align-content: content;">세로 가운데 정렬</div>
    </div>
  </body>
</html>
```
